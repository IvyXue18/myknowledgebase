# 两个库怎么用

## 面面的知识库

承载个人与生活、长期方向、学习专题、兴趣、日常记录。按问题与领域组织，概念、课程、人物和案例放在相关专题附近，不再要求分别进入顶层类型目录。

## Obsidian Vault 工作台

承载项目追踪、客户沟通、需求与报价版本、经营数据、选题、写作素材、草稿和已发布内容。写作 skill 的已有训练语料继续留在原路径。

## 日志和复盘怎么分

| 正在记录什么 | 主要位置 |
|---|---|
| 当天经历、随想与感受 | 本库日常记录 |
| 自我特点、生活需要与长期取舍 | 本库个人与生活 |
| 个人月度计划与复盘 | 本库方向与规划；继续沿用我的行动系统 |
| 客户项目发生了什么、结果与下一步 | 工作台对应项目 |
| 围绕学习问题做的小实验 | 本库对应专题；明确输入、实际结果与限制 |
| 从实践里提炼的可复用方法 | 本库对应专题，并链接原项目证据 |

混合记录不强拆；需要时另写简短结论并链接原文。外部说法、AI 整理、个人判断、实际验证分别标明，不把旧计划当作新承诺。

## 维护方式

- 收集时允许先放收件箱；有了自己的收获，再吸收到相关专题。
- 文件只维护一份正文，跨专题用链接；跨库使用包含库名和文件路径的 Obsidian 链接。
- 飞书继续保存图片和表格丰富的内容，本库记录必要摘要与原文入口。
- 写作 skill 默认读取工作台已有语料，不因目录调整自动扩大到私人日记和自我认知。
- 一个专题只有一篇笔记时不必先建多层目录；材料实际增长后再拆分。
