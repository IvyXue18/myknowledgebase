# 销售型内容写法

> 从梁靠谱 89 篇公众号拆出来的方法，用来改社媒虾的产品内容。
> 性质：AI 研究，2026-11-23。每条都附原文编号，逐篇证据见 [[2026-11 逐篇拆解]]，原文见 [[09_Raw/wechat/梁靠谱/00-说明与索引|09_Raw]]。
> 还没有经过面面验证。写进写作 skill 之前，先用改写对照试一遍（见 [[社媒虾改写对照-同时盯30个对标账号]]）。

## 先说结论

她的文章让人想买，主要不是靠文笔或语气，而是靠写作顺序：

**先替读者把问题重新想一遍，让他看到原来的解法为什么不行、拖着要付出什么代价；等他自己得出"得换个办法"，产品才出场，而且只出现一两次。**

社媒虾现在的写法正好反过来：先介绍功能，再说这个功能能解决什么。读者还没意识到自己有这个问题，所以看完觉得"挺好"，但不会想买。

还有一个常见误解要先纠正。她嘴上常说"别讲功能"，可她真正卖货的文章（L009、N009、N018）都把模块一个个列出来了。她的做法其实是：**每个功能都先翻译成一个卡点**，后面再跟一句"你不需要……你只需要……"。所以要改的不是"不讲功能"，而是"不单独讲功能"。

## 〇、先有真人，再有结构（2026-11-23 补）

按这份方法第一次改社媒虾的 5 篇站外文章，面面看完说：完全不像真人写的，像罗列出来的要点。原因是这份方法只总结了推进顺序，没总结她的真人感从哪来。照着顺序往稿子里加句子，加出来的还是要点。

回头细读 L094、H162、N016，她的真人感来自这几样，**比第二节的推进顺序更重要**：

1. **从一个真人真事开头。**"前几天我有学员问我，客户说帮他们宣传，应该怎么去答谢呢？"（L094）；"之前有人在公众号追着我骂"（H162）。
2. **写自己当下的反应和心里话。**被骂开终身制早死了怎么办，她"还认真算了一下，我的寿险杠杆"，最后来一句"因为还想再体验一下世界哈哈哈"（H162）；"几年前我的脾气完全不这样"。
3. **把会说的话原样写出来。**不说"要先肯定对方"，而是直接写"那太好了，你不仅人的认知和执行牛，你的人脉和转介绍也牛"（L094）。
4. **一直在跟读者说话。**"不信你想想""有没有觉得鸡皮疙瘩都起来了？""你们有没有遇到过这样的人？"
5. **会岔开，会开玩笑。**讲强关联时扯到训狗，还替狗配心理活动："我从小就离开了妈妈，我实在是太可怜了"（L094）。
6. **连着说，几乎不用列表。**短文常常没有小标题，没有固定字段，一段接一段像在说话。
7. **敢说真话，有态度。**"我上网本来也是为了赚钱，不是为了交朋友"（H162）。
8. **产品是生活里顺带出现的。**"我在写这篇公众号的时候，这个老师还没有来加入销冠群，等我发出来的时候，已经加入三天"（H162）。

**放到面面身上**：真人感只能来自面面自己的真事，不能编。动笔前先找真实素材（做产品的经历、用户原话、客户群的问题、自己踩过的坑），用它开头，再讲方法和产品。找不到就标「待补充」或先问面面，不要用"比如做内容的周一要交选题"这类推出来的场景顶替。第一次按这个思路写的是《小红书怎么爬取数据》，面面认可了方向，之后同一批另外 4 篇也照这个思路重写了（工作台 `市场部/选题库/`）。

## 一、先看清文章在她的生意里干什么

**1. 一篇文章不负责成交。** 她给成交画了一条进度条：看公众号到 30%，看朋友圈到 70%，看直播到 90%，聊几句到 100%（H014）。文章只负责前面那一段：让人认出问题、相信她懂、愿意加她。

**2. 多数文章不卖。** 连续 20 篇新文（N001–N020）里，只有 7 篇结尾直接邀请购买。教别人怎么卖的 23 篇里，有 11 篇顺带卖自己的课，邀约都在全文最后 10% 以内，几乎不标价。讲自己创业经历的文章基本不报价、不制造紧迫，真正催单的动作放在朋友圈和社群里（01 专题小结）。

**3. 不卖的文章也在为成交铺路。** 观点随笔在立规矩、筛读者：求助类文章（L077、N002、N016）教学员怎么做一个"值得被帮的人"，顺带劝退伸手党。这些文章还反复强化同几条价值观，例如"问题在自己""少琢磨多搞钱"，正好是她销售培训的底色（05 专题小结）。

**4. 复盘本身就是广告。** 她在 H070 里说，把怎么卖产品的方法论写出来，"本身也是产品最好的广告"。她的战报和复盘文章（H018、H070、H151、H386），一边教方法，一边证明产品有效。

**5. 每篇都有固定出口。** 所有文章的"阅读原文"都链到同一个视频号小店。

## 二、一篇卖货文怎么推进

下面是从 N005 的五步法、H429 的示范、L009 和 N018 两篇正式卖货文里合出来的顺序。不是每篇都要走完，但顺序基本不变。

| 步骤 | 做什么 | 原文例子 |
|---|---|---|
| 1. 对号入座 | 列 4–5 个具体的卡点，再加一句"中了三条以上就认真看完" | L009 的四个"破防瞬间"；N018 的资料自检；N007 的 8 个死循环，每个配一句对话 |
| 2. 重新解释问题 | 把读者以为的原因，换成一个新的原因，最好配一个日常类比 | N018"你只有存的动作，没有取的入口"；L009"不是你不会说，是你没「系统」"；N008 课程是公式，答疑是审题 |
| 3. 拆掉替代方案 | 替读者说出常见卖点或现在的做法，再用"更便宜的能不能做到"一个个拆掉 | H429"几十块钱的AI软件能不能做到呢？"；L033 找"别人有的，但用户已经受够了"的地方 |
| 4. 找一个拖不得的时刻 | 从产品的一个属性出发，问"哪个场景拖不得"，落到具体时段和具体冲突 | H429 从"及时高效"推到"晚上家里吵架" |
| 5. 算代价 | 写拖着不解决，短期付出什么、长期付出什么 | H429 当晚一起哭、第二天没精神，长期影响亲子关系 |
| 6. 给读者开脱 | 把"你不行"改成"你缺一个方法"，给产品留出位置 | H429"他们很多的时候只是缺少一些方法" |
| 7. 产品出场 | 每个功能挂一个卡点，后面接"你不需要……你只需要……" | L009"你不需要背话术，你只需要知道「这个问题，我之前见过」" |
| 8. 交付写成路径 | 写清第一步做什么、每一步多久、拿到什么；能写成数字结构就写 | N018 三份文件加 D1–D7；L095"2 年、5 模块、6 权益"；N005"讲路径，不讲门槛" |
| 9. 证据 | 自己用过、自己拿到结果、能查到的客户 | N005 结果要"能查到的"；H342 要"活的客户" |
| 10. 劝退 | 写清谁不该买 | N018"这个产品，不治懒病"；L095 劝退小白；H062 不写大纲不接 |
| 11. 价格 | 用会员价或更贵的服务做锚点；降价要给理由 | H062 单次 1999，会员不限次；L009"不是为了降价促销" |
| 12. 结尾 | 给一个具体动作，最好给两个选项，不问开放问题 | L007"我建议周三下午或者周五上午"；N018 扫码时备注"救急包" |

**第 3 步最值得先学，也是社媒虾最缺的一步。** 社媒虾文案里的"AI 分析""数据全""效率高"，任何同类工具、甚至直接问一个 AI 对话框都能这么说。H429 的做法是：先把这些说法摆出来，再一个个拆掉，最后留下只有自己能说的那一条。

## 三、她反复用的几招

**重新解释问题时，配一个日常类比。** 存和取（N018），公式和审题（N008），游泳池（L055），苹果生态（H080）。类比要让读者一听就懂"原来问题在这"。

**卖人的变化，不卖产品本身。** 她会接着追问"然后呢"。H247 问"上岸了然后呢？"，N005 说"用户买的从来不是产品，是产品带来的生活"。L020 写的是"靠AI干活的人"，而不是"用过AI的人"。

**用"这不是 X，而是 Y"给产品定位。** N009 说"这根本不是一门教你「怎么用工具」的技术课"，一句话把产品从工具类拉到结果类。

**每段功能都用一个用户问题开头。** N009 的课程介绍，每一段都先抛一个读者会问的问题。

**主动承认营销味。** 有人说她营销味重，她直接承认自己就是商人。对犹豫的人，她说"我可能更犹豫是不是收下你"（H162）。她还公开自己的商业逻辑，比如终身制和 100% 佣金到底怎么赚钱（H109）。这比假装不卖更让人信。

**给推荐人一个现成的包。** 宣传发在哪、用哪段文案和哪张图、发完能拿到什么，都提前准备好（L094）。

## 四、同一个产品，换着角度卖

销冠孵化基地在两年里至少有 12 种卖法：
- 海报加倒计时
- 公开终身制的商业逻辑
- 训练营战报
- 把质疑者变成买家的故事
- 作为峰会的赠品
- 线下请吃饭
- AI 谈单智能体
- 创始人本人答疑

2024 年主要卖"终身绑定和社群生态"，2026 年转向"AI 智能体"和"四千人我亲自回"（02 专题小结）。

资料库急救包隔 4 天发了两篇，同样 99 元，写法完全不同：
- **N018 以问题为主线**：重新定义问题，列交付清单和 7 天路径，有劝退，有原价锚点，前 100 名送书。
- **N020 以人物为主线**：讲落薇这个人，加上三天的销量和涨价时间，几乎不提交付内容。

**放到社媒虾上**：一个功能至少可以写成四篇，分别是问题文、用户故事文、"这个功能为什么这样设计"的逻辑文，以及一次真实使用的复盘文。不用每次都从功能清单写起。

## 五、她怎么持续产出

| 环节 | 她的做法 | 出处 |
|---|---|---|
| 选题 | 约 80% 来自用户提问；常见问题写成文章，代替一对一回答 | H175 说约 80%；L015 说「问题是最好的老师」；内容生产专题里 9 篇以上开头就是一个提问 |
| 草稿 | 先在朋友圈写两三百字，攒下来的就是公众号草稿 | H274 |
| 成文 | 写一篇 1000–1500 字的公众号要 15–30 分钟 | H274 |
| 一稿多用 | 阅读量高的内容批量拍成视频，一个下午拍 100 条，再讲成直播 | L024 |
| 交付产物变素材 | 群精华、谈单拆解、学员复盘、点评截图都能直接写成文章 | H018、H070、H151、H310 |
| 固定事件 | 拉新、峰会、训练营，每次都出一篇战报或复盘 | 01 专题小结 |
| 人手 | 排版、剪辑、物料交给兼职助理和内容合伙人 | H018、H151、H206 |

她在 H109 里自己说了这个循环：一直交付用户，才能保持一线的手感和选题来源，然后再写内容引流和成交。

篇幅上也有变化：2024 年上半年她写 7000–12000 字的长文，从下半年起改成 1000–2000 字。H274 里她说 1000–1500 字"最容易入池"。她写作用不用 AI，原文没有说；L015 只提到用 skill 帮甲方批量写。

**放到面面身上**：面面没有她那样的交付量，也没有团队。能借的是选题入口和一稿多用：
- 用户反馈、客户群里的提问、工单，先写成短帖。
- 攒够了再扩成公众号。
- 社媒虾自己采到的数据，也可以拿来补选题。
- 每次发版或者服务完一个客户，固定写一篇复盘。

## 六、不照搬的

| 她的做法 | 为什么不搬 | 出处 |
|---|---|---|
| 把损失一路推到极端（亲子冲突，推到抑郁甚至犯罪） | 社媒虾的读者是理性的运营，这样写会显得廉价；代价要停在工作层面，最好能量化 | H429、H339 |
| 绝对化承诺，如"完全规避""不可能不成交的" | AI 工具的输出本身有不确定性，有广告法风险，用户第一次碰到错就不信了 | H429、H413、H003 |
| 无法核实的数字，如 1200 万 6 天、70% 转化、GMV | 社媒虾的用户是做数据的，最容易识破；要换成能复现的例子，写清账号、样本量、时间，配截图 | L096、H194、H003 |
| 段位审判、贬低用户现在用的工具 | 会把正在用别的工具的潜在用户推走，也和面面的风格不合 | L020、H413、L007 |
| 命理、影视和古籍堆背书 | 工具的可信度要靠真实输出，不靠类比 | L041、H429 |
| 拿现场冲动购买当证据 | 工具有试用和复购周期，冲动买来的用户留不住 | H429 |
| 夸张的价格锚，如 9800 降到 998 | 订阅或积分制的价格会显得不可信 | N009 |
| 靠创始人人设和私人关系成交 | 需要多年的个人 IP 才成立 | H371、N020 |

## 七、她自己也没做到的

下面这些不是挑刺。它们说明可以学她的结构，但不能学她的夸张：
- 她要求证据要"能查到"，自己用的却多是自报数字（N005 对比 L096、H194）。
- 她批评别人的焦虑话术，自己在 H429 里用的正是同一套（H339 对比 H429）。
- 有几篇标题和正文对不上：L055 标题说取消一对一，正文说没打算取消；H417 标题写"一个月卖出20套"，正文没有对应内容。
- 学员人数前后口径不一：近 4000（H413）、3000+（L095）、四千（N008）。

## 八、写社媒虾产品文前的检查表

动笔前先回答下面这些问题。答不出来的标「待补充」，不要硬写：

1. **谁，在什么时刻？** 具体到哪类人、哪个任务、哪一天，比如周一上午要交本周选题，周日晚上还在刷对标号。
2. **他现在怎么做，受够了哪一点？** 只写来自真实用户反馈的抱怨，不要自己编。
3. **哪些卖点要删？** 列出三个常见卖点，把"直接问 AI 也能做到"的那几个删掉，剩下的就是只有社媒虾能说的。
4. **拖着不解决的代价是什么？** 停在工作层面，能量化就量化。
5. **他缺的是什么？** 用"不是你不行，是缺……"的方式写。
6. **每个功能对应哪个卡点？** 每个功能后面写一句"你不需要……你只需要……"。
7. **怎么开始用？** 写清第一步做什么、要多久、能看到什么。
8. **证据在哪？** 用真实账号，写明样本量和时间，配截图，最好是用户自己的话。
9. **谁不该用？**
10. **结尾的动作是什么？** 一个具体动作，或两个选项。
11. **功能还在吗？** 对照当前功能清单逐项核对，查不到的就不写。

## 九、怎么接进写作 skill（计划）

1. 先拿一篇社媒虾文章按这个方法改写，让面面看前后差别。
2. 面面觉得有用、真的改过或发过之后，把第二节的推进顺序、第六节的禁区、第八节的检查表压缩成 `mianmian-wechat-writer/references/sales-content.md`。写产品文、发售文、服务介绍时才加载。
3. 在 skill 的校准记录里写清楚：这些规则的来源是梁靠谱研究，验证依据是哪一篇改稿。
