## 为什么她是我的贵人

- 我的判断：她正好补上我最弱的一环。我擅长产品和交付，获客和营销一直做不起来；她擅长商务、销售和战略，自己说对交付「真的很懒」。她的原话是「你擅长专业，我擅长商务」。
- 她把我当战略级合作伙伴，不当外包。报价时她反复要我「报充分」，说「不能以员工的模式去做报价」，还说「只有充分的价格和收益，大家才有兴趣做事」。
- 她带来的是 B 端高客单机会（欧博、雪豹日化，明年的 QS 智能化），还有十几年 IP 操盘沉淀下来的方法论。这正好给了我另一条路。
- 她看人的角度拆掉了我一个长期的内耗（见下文「她对我说的话」）。

## 我对她的感受（2026-09-26）

- 我对她是有感激的，也有一份比较重的、不可辜负的信任。
- 她能拿下的单子，在我看来级别非常大，几十万上百万。我还没有单独、独立地做过这样的事，所以会有一点信心不足，担心自己撑不撑得起这样的交付强度。但她给了我很大的信心。
- 另一方面，我觉得市面上很多也是草台班子，我的能力和认真程度是可以解决问题的。解决不了就请外援，报价里也会把这部分考虑进去。
- 跟她在一起，我好像激发出了一些比较正能量的东西，不管是对自己的信心，还是别的。

当时 AI 的回应里有两点值得留下（属于 AI 建议，不是我已经验证的结论）：
- 几十万上百万的总价里同时包含商务、策略、开发、团队协作和后续服务，不需要我一个人变成无所不能。要看清的是哪些结果由我负责，以及我有什么资源把它们做出来。
- 从「靠自己的时间把事情做完」走向「组织足够的能力，把结果交出来」：对不熟悉、又会影响整体交付的部分，提前找人评估，把外援写进方案。

## 她是谁

- 她说：甘肃人，31 岁，性格偏 I。之前一直在杭州工作，今年搬到西安和父母住。
- 她说：2021 年去了抖音，掌握了抖音内部的方法论。出来后跟着国内做 IP 最厉害的一批编导一起给客户做 IP，把他们的方法论「蒸馏」了下来。母公司是如涵，国内第一家在纳斯达克上市的网红孵化型 MCN。
- 她说：大约五年前离开上班状态出来创业，后来被前老板拉成合伙人。团队目前做 IP 陪跑和企业内容战略，今年开始盈利。
- 团队（09-22 群里介绍）：老季（季淑贤）负责运营，忘忧（陈静）是项目经理。她评价两人「扎实、靠谱且自驱」，不属于强思考型，但认真、有行业经验。
- 她说：身边有很多企业家朋友，大部分客户靠老客户续约和转介绍来。她不做自己的账号，因为 to B 的客户线下就能搞定。

## 她的 IP 方法论（我学到的）

| 知识点                    | 她的说法                                                                    | 我的收获                                 |
| ---------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| 有效人设 = 用户购买你的理由        | 人设不是标签，要控制在三个词以内，找的是这个行业里的「第一购买因素」。比如汽车贴膜店，要展示的是「老实」，不是「专业」，因为专业只是服务的底线 | 可以沉淀成按行业分析第一因素的模型，这正是 AI 从互联网上学不到的部分 |
| 定位 = 跟什么人群、通过什么方式、说什么话 | 五维定位：商业 → 人群 → 人设 → 内容 → 平台                                             | 和产品定位同构：什么场景下，帮哪群人，解决什么问题，对方付多少钱     |
| 痛点要以小见大                | 肥胖人群真正的痛点是自卑，不是健康；开头要从小场景切入，比如「健身房传单总是先塞到我手里」                           | 在提示词里只告诉 AI 这一个微操，再给两三个例子，产出就明显变好    |
| 人群按欲望划分                | 用「欲望 + 场景 + 身份」来定义人群，场景要经得起事实检验，比如想升岗、被表达力卡住的人                          | 用来检查 AI 生成的人群有没有虚构的场景                |
| 卖欲望，不卖解决问题             | 「不要把账号做成图书馆，要做成成人用品店」：告诉用户产品能让他成为什么样的人                                  | 用于写选题和脚本                             |
| 系统的价值在微操               | 大框架搭简单，再把一两档高质量的微操一点点填进去；她用 Obsidian 知识库加智能体来沉淀这些微操                     | 和我做 AIOS、MediaClaw 的思路一致             |
| 拍摄看的是自然，不是美            | 大部分人会经历「样板戏阶段」，还原到线下聊天的状态就及格了                                           | 可以做成拍摄诊断的打分维度，待验证 AI 能不能判断「自然」       |

## 她的商业判断

- B 端和 C 端：国内核心是卖高客单。B 端信息差大、效果看得见，「微操」能直接变现；C 端的用户感知不到这些微操，而且产品容易被抄。她说「你擅长 C 端，那我们做出来 C 端也挂着卖」。
- 知识系统化：给别人做 IP 太累，把知识结合 AI 做成系统卖，再加轻服务，比单卖服务好。我当时的回应是，光软件会被当成工具，必须有 IP 或一些服务。
- 价值定价：价格由客户对价值的认可决定。她压着不和客户谈价，要等「我们两个人都满意」之后，再在我的价格上加商务溢价。
- 客户节奏：大企业年前花钱、年后收紧，所以要提前半年提案，赶在年前拿到明年的预算。她更喜欢和南方企业家合作，觉得「打钱爽快」。
- 战略能赚钱：雪豹日化业绩翻倍，她归因于战略定位正确（科研型、医护级品牌，避开和网红品牌硬拼），加上执行时抓住了最关键的一环（小红书和知乎种草）。她说这是她现在赚钱的核心来源，背后有一位师傅给大方向。

- 对 AI 时代的看法（她说）：最重要的是人的愿力，把身体、愿力和情绪养好，才是这个加速期的「决胜法宝」。
- 做事风格：擅长定方向，定完就放手；认为给团队下 DDL 比提问题更有效。我在群里要 @ 到人，并写清完成时间。
- 为人：热情、爱开玩笑，邀请我去西安吃她妈妈养的羊、住她家。她也喜欢历史。

## 和她合作的提醒

## AI 观察与合作建议（2026-09-26）

> 以下是 AI 根据三次通话和飞书聊天做出的判断，不是事实，也不是我已经验证的结论。

### 她在这段合作里的角色

她不是导师，也不是甲方。她是握着客户和定价权的前台，我是提供能力的后台。她赚钱的核心是客户对她这个人的信任，所以常常是先卖概念，再做系统。她卖出去的承诺，最后要由我的交付来兑现。

我感到的「不可辜负」不只是情绪，也是这个合作结构本身压在我身上的重量：她的信用在我手里，我的回报在她手里，我们互相押注。

### 值得注意的模式

1. **她很会认可人，这是真心，也是她做商务的方式。** 她给的信心可以收下，但对自己能力的判断，要建立在我自己做出来的结果上，让她的认可是锦上添花，而不是撑住我的那根柱子。
2. **她说自己定完战略就不管，所以交付的压力会自然流到我这边。** 她卖的规模很大（1 万个经销商、企业级、小程序只用 4 个按钮），承诺和系统实际能做到的程度之间会有落差。在她对客户开口之前，我就要参与决定承诺的边界。
3. **她的团队需要有人下 DDL，而她不会是那个人。** 我的角色会从「做系统」变成「做系统，同时带一部分项目管理」，这部分工作量要算进报价。
4. **最大的空白：做出来的系统归谁。** 雪豹做完后要复用给欧博、标准品和 QS，代码是我写的，方法论是她的，复用之后的收益怎么分还没人说过。要在系统真正值钱之前谈：现在谈是一起规划未来，以后谈就会变成争利益。
5. **有一些隐性投入。** 给完美提案做 demo 算不算钱、有没有上限；大企业付款慢，我的钱是否要等客户付了才给。

### 怎么跟她合作相处

- **把信任变成明确的约定。** 感激和不可辜负，最容易让我低报价、多承诺、不好意思说不。她要的是「两个人都满意」，会尊重清楚的条件，而不是我的自我牺牲。不辜负，是做到我答应的事，而不是答应所有事。
- **每一单开始前写清楚：** 交付范围、验收标准、我的价格、付款节点，以及付款是否和客户回款挂钩。复用和知识产权单独约定一次。
- **把这段合作当成学 B 端销售的机会。** 获客和销售是我最弱的一环，而她在这方面最强。争取旁听她的提案和客户沟通，学她怎么定价值、怎么提前半年铺提案。
- **保留我自己的主线。** 我的 B 端机会目前全部通过她进来。MediaClaw、C 端产品，还有我自己建的对标账号库和选题库，要继续握在自己手里。依赖一个人，对我们两个人都不健康。
- **沟通用异步和书面方式。** 她精力省着用，节假日会「消失」。决策集中处理，结论写成文字发到群里。
