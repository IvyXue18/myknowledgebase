# AI 视频制作

## 核心问题

怎么用 AI 把「录屏演示 + 讲解」做成有人味、能持续更新的视频：先服务社媒虾宣传，再试 IP 博主式的教程视频。

本页区分三种来源：**面面实践**（做过、有文件为证）、**外部观察**（拆对标看到的）、**AI 建议**（未验证的候选，不等于面面认可）。

现在的短板不在配音，而在**形态**：已有视频是「产品演示 + 配音」，主角是产品；IP 博主视频的主角是人设和过程。

## 三种视频形态

| 形态 | 例子 | 主角 | 难点 |
|---|---|---|---|
| 产品演示 + 配音 | 社媒虾宣传片、用户问系列 | 产品 | 录屏干净、一条只讲一个卖点 |
| IP 博主教程 | [[jumping clawd｜VibeCoding大赏]] | 人设 + 做事过程 | 口语化稿子、人设符号、梗和节奏 |
| 纯生成 / 动画短片 | AI 短剧、角色动画 | 画面 | 角色一致性、生成成本 |

先学第二种：它和已有能力（录屏、复刻配音、自动合成）重合最多，缺的主要是编导和包装。

## 制作流程地图

| 步骤 | 人做什么 | AI 能做什么 |
|---|---|---|
| 1 选题与钩子 | 选自己真做过、有结果的事 | 拉对标、列钩子候选（社媒虾采数据） |
| 2 口播稿 | 定观点和梗，读一遍改拗口处 | 出初稿、改口语化 |
| 3 录屏 | 真实操作一遍，过程留素材 | 自动推镜头的录屏工具、后期缩放 |
| 4 配音 | 选真人录还是复刻 | 声音复刻 TTS，带字级时间戳 |
| 5 剪辑包装 | 定节奏、放梗 | 自动字幕、贴纸、音效；或用代码批量合成 |
| 6 封面标题 | 选一个 | 出多版 |
| 7 发布复盘 | 看评论找下一条 | 社媒虾采完播、评论 |

## 工具候选（AI 建议，未验证）

- 录屏：Screen Studio、FocuSee（自动跟随鼠标缩放、加背景和阴影）；OBS 原录 + 后期推镜头。
- 配音：豆包声音复刻（在用）、MiniMax Speech、ElevenLabs、CosyVoice / Qwen-TTS；真人录音用剪映「智能剪口播」去气口。
- 剪辑包装：剪映 / CapCut（自动字幕、贴纸、表情包、音效库）；代码化合成用 HyperFrames 或 Remotion，适合固定栏目批量出片。
- IP 形象：即梦、Nano Banana 等出静态形象，再做 3–5 个固定表情和贴纸；像素风可以直接用 SVG 写。

## 练习路线

每次只做一个练习，做完在下面记一行结果。

1. **拉片 3 条 IP 博主教程**：用 `lapian` 只记结构、包装手法和人设符号。第一条已拆：[[jumping clawd｜VibeCoding大赏]]。
2. **复刻形式做一条 60–90 秒**：「我用 AI 做了 X，两分钟教会你」。X 选自己真实做过的事，例如用 Claude Code 做的某个社媒虾功能或 LarkPomodoro。
3. **配音盲听**：同一份稿子出真人录音、豆包复刻两版，给 3 个人盲听，记谁听出来了、在哪句听出来。
4. **做 IP 符号**：一个形象 + 3–5 个固定表情 / 口头禅 / 梗，在每期复用。
5. **发布并复盘**：用社媒虾采完播和评论，决定下一条。

## 试跑经验（2026-11-28，AI 总结，面面已看过结果）

1. **流程本身不是瓶颈。** 字幕 → 分镜 → 每个镜头一个 agent → 合成，一轮约 8 分钟、100 万 token 出头，能重复跑。
2. **画面有没有吸引力，主要看真实素材，和动效多精巧关系不大。** 第一帧要有真实、能读、有情绪的东西：真人原话、真实截图。动效负责划重点，不能代替证据。
3. **规范就是方向盘。** agent 会照字面执行：写「干净克制」就出刻板，写「不编造」就出灰色占位线。规范要写清楚观众该看到什么，不能只写美术要求。先改一个镜头验证规则，再铺开到全部，最省。
4. **素材质量决定上限。** 低清截图放大会糊；截图里的叫法和口播不一致（「改写」和「二创改写」），画面就对不上；没存的素材（GPT 那一版的原文）画面上就没法给。录素材时要截高清原图，对比类内容两边都要留证据。
5. **每个镜头单独做，整体节奏就没人管。** v3 中段连续三个镜头都是文档截图。拆镜头之前需要一步「全片节奏表」：哪里快、哪里停、哪里换画面形式。
6. **agent 会自己加文字。** 每轮都要人过一遍它加的标签和示例句。
7. **好不好看，最后还得人来判断。** 「两秒就划走」这种判断 AI 给不出来，正是猫学长 #06 说的「AI 缺感受」。

### 猫学长的技巧用到了哪些

| 用了 | 没用 |
|---|---|
| 先有声音，再转字幕（#06） | 情绪钩子设计（#15）：稿子沿用旧版，没重新设计开场钩子 |
| 主从架构：主控拆镜头，每个镜头一个上下文隔离的 agent（#06 #07） | IP 人设：形象、表情包、自嘲、固定梗（#05） |
| HyperFrames 写动画、按帧渲染（auto-motion） | 画面包装：录屏放进点阵画布浮窗、弯曲屏幕（#05 #15） |
| 共享规范当作 harness，按结果迭代规则（#07） | 自动音效：按动画帧卡点配音效（#13）。旧版有音效，v3 没有 |
| | 同一镜头并行做几版再挑（#13 的 cmp 图、#15 的 15 种风格并排） |
| | 先找高质量动效复刻，再换成自己的内容（#10 motion face），用来解决刻板 |
| | 迪士尼动画法则 skill，让动作不僵（#05） |

用到的基本都是**生产线**（怎么自动出片），没用到的基本都是**吸引力**（钩子、人设、包装、声音、多版挑选）。这次的问题也正出在吸引力上。
